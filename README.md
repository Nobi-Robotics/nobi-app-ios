# nobi-app-ios

Nobi's iOS companion app for pairing and managing Nobi robots over Bluetooth.

Requires iOS 17.0 or later. Open `Nobi.xcodeproj` in Xcode and select the `Nobi` scheme to build and run the app.

The project can be regenerated with [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```sh
xcodegen generate
```
